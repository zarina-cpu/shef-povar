# Шеф из того, что есть дома

Одностраничное приложение: продукты + техника → Gemini → название, шаги, калории.

## Стек и ограничения

- **JavaScript**, без TypeScript: Next.js App Router, React, один `app/globals.css`.
- ИИ только на сервере: `GEMINI_API_KEY` в `.env.local`, клиент бьёт в `POST /api/recipe`.
- Для новых фич по умолчанию предлагай JS-библиотеки; спрашивай, нужен ли переключатель светлой/тёмной темы, если UI сильно меняется.

## Карта файлов

| Файл | Назначение |
|------|------------|
| `app/page.js` | Форма, состояние, fetch API |
| `app/api/recipe/route.js` | Валидация, вызов Gemini, ошибки на русском |
| `lib/gemini.js` | Промпт, `parseRecipe`, список моделей |
| `components/RecipeForm.js` | Продукты, чипы техники, `resolveEquipment` |
| `components/RecipeCard.js` | Карточка рецепта |
| `components/ThemeToggle.js` | `data-theme` + `localStorage` ключ `shef-theme` |

Подробный контракт JSON и промпт: [references/gemini-recipe.md](references/gemini-recipe.md).

## Порядок в API

1. Распарсить JSON тела.
2. Проверить `ingredients` (≥3 символа) и `equipment` — **до** проверки ключа.
3. Проверить `GEMINI_API_KEY`.
4. Вызвать модели из `GEMINI_MODELS` по очереди, `responseMimeType: application/json`.
5. `parseRecipe(text)` → `{ recipe }`.

## UI и тема

- Палитра: светлая фон `#E1B12C`, карточки `#FFFFFF`, неактивные теги `#F5E6BA` / hover `#ECD9A5`, акцент `#E62222`; тёмная `#23272A` / `#2C3135` / `#F03A3A`.
- Глаза котика: хочу `#32B3B3`, готовила и время `#E1B12C`, ккал — бирюза.
- Шрифт: Jost (кириллица). Карточки 1rem, теги и кнопки — капсулы.
- Сохраняй контраст кнопок и чипов в обеих темах; выбранный чип — `--pine`, основное действие — `--accent`.
- Чипы техники включают «все»; ниже — тип блюда. Сохранённые рецепты: `lib/savedRecipes.js` + localStorage `shef-saved-recipes`.

## Типичные доработки

- **Новая техника**: пресет в `RecipeForm.js` + правило в промпте в `lib/gemini.js`.
- **Другие поля** (аллергии, время, тип блюда): расширить тело POST, промпт и `RecipeCard`.
- **Ошибки Gemini**: понятные сообщения в `route.js`, не светить ключ на клиент.

## Проверка

- `npm run dev`, форма с реальным ключом.
- Без ключа — сообщение про `.env.local`.
- Пустые продукты — 400, не 500.
- Переключение темы и перезагрузка страницы.
